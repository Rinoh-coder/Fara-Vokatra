# Configuration expérimentale

Les fichiers de ce dossier décrivent les paramètres d’expérience qui ne doivent pas être cachés dans le code. Toute modification doit être revue comme une décision méthodologique.

- `zones_madagascar.json` contient les boîtes d’échantillonnage de la première comparaison multi-zone.
- Les dates, produit CHIRPS, seuil de couverture et paramètres d’onset doivent être conservés dans les manifestes et fiches d’expérience.

Les boîtes sont des emprises techniques. Elles ne sont pas des frontières administratives et ne doivent pas être présentées comme telles.
